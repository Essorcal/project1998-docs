The @Command Scroll

Every chat command the server answers, grouped as the source groups them. Commands above your tier answer Unknown command. — gated tooling is indistinguishable from a typo, so this sheet is the only place a tester sees the GM roster. In game, @commands is the compact index and @help <word> the search; this page is both at once.

Tiers stack. Player commands work for everyone; Tester adds the world/character/item tooling; GM adds moderation, spawning, config, and the RE probes. Staff level is re-read from StaffAccounts on every command, so a demotion lands immediately.
Session toggles reset. @clip and @anywarp are per-session and always OFF at login, so a waiver can never follow a character into normal play. Both narrate what they waive.
Rebuilds win. @lvl / @class / @mark / @align rebuild stats and the spellbook from the curve — set class and level first, then poke individual stats, pools, or one-off spells.
